# StayZo 🏠

StayZo is a full-stack property rental platform where users can create, manage, and browse property listings. It includes image uploads, secure authentication, and a clean interface. Built using Node.js, Express, MongoDB, and Cloudinary.

## ✨ Features

- 🧑‍💼 **User Authentication** (Register/Login/Logout)
- 🏠 **Listings CRUD** (Create, Read, Update, Delete)
- 📤 **Image Upload to Cloudinary**
- 🔒 **Authorization & Middleware**
- 🔍 **Search Listings by Title or Location**
- 🗺️ **Location-based Listings** (if `mapbox` or similar used)
- 📅 **Booking System** (optional)
- ⭐ **Review & Rating System** (optional)
- 📱 Responsive Design
